# Querywise: the from-scratch version (archive)

This is a frozen snapshot of the first implementation of Querywise's backend: the agent loop, tool
schemas, streaming, human approval and memory, all written by hand with plain Python and the
`ollama` client, with no agent framework.

The live backend in [`../../backend`](../../backend) is a LangChain / LangGraph re-implementation of
the same behavior. This copy is kept as a readable reference and as a baseline to compare against.
Nothing in the main app imports it.

It is also tagged in git as `v1-basic-python`.

## Why keep it

- It shows what the framework hides: the tool-calling loop, pause and resume, and event streaming
  are about 300 lines of explicit code in [`app/agent.py`](app/agent.py).
- It is the control group for evaluation: same questions, same data, two implementations.

## Run it (optional, on port 8001)

It uses the same dependencies and the same `backend/data` folder. From the `backend` folder:

```bash
uv run uvicorn app.main:app --app-dir ../archive/basic-python --port 8001
```

The React UI talks to port 8000. To try this version with the UI, change `API` in
`frontend/src/api.js` to `http://127.0.0.1:8001`.

## Differences from the current backend

| Topic | This archive | Current backend |
|---|---|---|
| Model calls | `ollama.chat` | `ChatOllama` |
| Tool schemas | hand-written JSON | generated by `@tool` |
| Agent loop | custom `while`-style loop | LangGraph `StateGraph` |
| Approval pause | in-memory `PENDING` dict | LangGraph `interrupt()` and a checkpointer |
| Extra endpoints | `/ask`, `/search`, `/web-search`, `/ollama-check`, `/agent` | removed (unused by the UI) |
